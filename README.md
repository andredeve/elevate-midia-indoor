# Elevate Mídia Indoor — Painel de Gestão & Plataforma DOOH

Plataforma completa de gestão, transmissão e monetização de telas de mídia indoor em geral (estabelecimentos comerciais, clínicas, restaurantes, condomínios, lojas, academias, shoppings e espaços corporativos).

## Identidade Visual (Elevate Mídia Indoor)
- **Gradiente Principal:** Magenta/Violeta (`#d932fc`) -> Roxo (`#8a08ff`) -> Índigo Elétrico (`#3b01fd`)
- **Superfícies:** Dark Obsidian (`#08080c` / `#111118`) e Light Mode (`#f8fafc` / `#ffffff`)
- **Logos:** `/public/logo.png`, `/public/logo-dark.png`, `/public/logo-light.png`, `/public/favicon.png`

## Como Executar

```bash
npm install
npm run dev
```

Para gerar a build de produção:
```bash
npm run build
```
